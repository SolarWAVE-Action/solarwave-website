# solarwave-website
This repo contains the SolarWAVE Action website created using GitHub Pages, Jekyll, and Claude.

## Research & Education section (/blog/)
Everything under `/blog/` is the SolarWAVE Action Research & Education Initiative's nonpartisan research and education section.
- Every post sets `research: true` in front matter. This points the site's Donate links to the c3 research path (`/donate/research/`).
- Keep posts free of calls to action on specific legislation, and don't link to SolarWAVE Action (c4) campaign pages from them.
