# solarwave-website
This repo contains the SolarWAVE Action website created using GitHub Pages, Jekyll, and Claude.

## Research & Education section (/blog/)
Everything under `/blog/` is the SolarWAVE Action Research & Public Education Initiative's nonpartisan research and education section.
- Every post sets `research: true` in front matter. This points the site's Donate links to the c3 research path (`/donate/research/`).
- Posts funded by SolarWAVE Action Research & Public Education Initiative (c3) also set `funding: c3`. This shows the ASES funding line in the notice under the byline (`_includes/research_notice.html`).
- Keep c3 posts free of calls to action on specific legislation, and don't link to SolarWAVE Action (c4) campaign pages from them.
